# n8n Integration Project

Claude Codeからn8n Cloudのワークフローを作成・管理するプロジェクト

## セットアップ

### 1. APIキーの設定

`.env` ファイルを編集して、あなたのn8n Cloud情報を設定してください：

```bash
N8N_API_KEY=あなたのAPIキー
N8N_INSTANCE_URL=https://あなたのインスタンス.app.n8n.cloud
```

### 2. n8n CloudのAPIキー取得方法

1. n8n Cloudにログイン
2. 右上のアカウントアイコン → **Settings**
3. 左メニューから **API** を選択
4. **Create API Key** をクリック
5. 生成されたキーを `.env` ファイルに貼り付け

### 3. インスタンスURLの確認

n8n Cloudのダッシュボードで、ブラウザのアドレスバーに表示されているURLをコピーしてください。
例: `https://your-instance.app.n8n.cloud`
