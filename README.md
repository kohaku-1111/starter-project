# 🎮 マリオスタイル プラットフォーマーゲーム

HTML5 Canvas と JavaScript で作成されたマリオ風のプラットフォーマーゲームです。

## 🎯 ゲームの目的

プレイヤーを操作して、敵を避けながらコインを集め、ゴールの旗を目指します！

## 🕹️ 操作方法

- **← →** (矢印キー左右) - キャラクターを移動
- **スペースキー** または **↑** (矢印キー上) - ジャンプ
- **R キー** - ゲームをリスタート

## ✨ ゲームの特徴

### プレイヤー
- マリオスタイルのキャラクター（赤い帽子と口ひげ）
- スムーズなジャンプ動作
- 左右の方向に応じた向きの変更

### ゲームシステム
- **重力と物理演算** - リアルな動きを実現
- **プラットフォーム** - 様々な高さの足場を飛び移る
- **コイン収集** - コインを集めてスコアアップ（1枚100点）
- **敵キャラクター** - 紫色の敵を避けるか、上から踏みつける（200点）
- **ライフシステム** - 3つのライフでチャレンジ
- **ゴール** - 金色の旗に到達するとクリア（ボーナス1000点）

### ゲーム要素

#### スコアリング
- コイン取得: +100点
- 敵を踏む: +200点
- ステージクリア: +1000点

#### 敵との戦い
- 敵に横や下から当たるとダメージを受ける
- 敵の上から踏みつけると倒せる
- 倒した敵は消える

#### ライフシステム
- 開始時: 3ライフ
- ダメージを受ける、または奈落に落ちるとライフが減る
- ライフが0になるとゲームオーバー

## 🔧 カスタマイズ

`game.js` を編集することで、以下をカスタマイズできます：

```javascript
// ゲーム定数
const GRAVITY = 0.6;        // 重力の強さ
const JUMP_FORCE = -12;     // ジャンプの高さ
const MOVE_SPEED = 5;       // 移動速度
const ENEMY_SPEED = 2;      // 敵の移動速度
```

レベルデザインは `createLevel()` 関数で変更できます。
